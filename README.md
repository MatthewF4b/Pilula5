# Exercício 5 - Sistema de Cupons

Projeto separado utilizando várias classes e pastas.

## Estrutura
- models
- services
- tests

## Como executar

1. Abra no VS Code
2. Crie o ambiente virtual:
python -m venv venv

3. Ative o ambiente virtual:
venv\Scripts\activate

4. Instale as dependências:
pip install -r requirements.txt

5. Execute os testes:
pytest -v

6. Execute o sistema:
python main.py
